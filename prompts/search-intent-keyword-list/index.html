Search intent analysis for a keyword list

Classify a list of keywords by search intent and funnel stage, and get the best page type, content angle and priority for each one.

Published
November 20, 2026
Works with
ChatGPT, Claude and Gemini
Level
Intermediate
By
GoodAIPromt editorial team

Ranking depends on matching what the searcher wants: a guide, a comparison, a product page or a tool. Writing a blog post for a keyword where Google shows product pages rarely works. This prompt sorts your keywords by intent and tells you what kind of page to create for each.

The prompt

You are an SEO strategist. Analyse the search intent of these keywords.

My website and what it offers: 
Keywords (with volume and difficulty if I have them): 
Pages I already have: 

For each keyword give a table row:
- Intent: informational / commercial investigation / transactional / navigational
- Funnel stage: awareness / consideration / decision
- Best page type (guide, list, comparison, product, category, tool, landing page)
- Content angle in one line
- Whether an existing page should target it (name it) or a new page is needed
- Priority (high / medium / low), based on relevance to my offer and intent

Then:
1. Group keywords that one page could target together.
2. Flag keywords where intent is mixed or unclear and tell me what to check in the search results.
3. Suggest the first 5 pages to create.

Base volume or difficulty only on numbers I gave; don't invent them.

0 of 3 blanks filled

How to use it

  1. Export keywords from your SEO tool with volume and difficulty.
  2. Search the unclear keywords yourself to see which page types rank.
  3. Create pages in the suggested order and track results.

Tips

  • Ask for a brief for each of the first 5 pages.
  • Recheck intent every few months — search results change.

Frequently asked questions

What does this prompt do?

Classify a list of keywords by search intent and funnel stage, and get the best page type, content angle and priority for each one.

Which AI tools does it work with?

It is written for ChatGPT, Claude and Gemini. It also works in other AI tools that accept text prompts, with small changes.

What do I need to fill in?

3 blanks: website and offer; keyword list; existing pages or "none". Click each blue blank on the page, type your details and press Copy prompt.

Is this prompt free to use?

Yes. You can copy and use it for personal and commercial work.
