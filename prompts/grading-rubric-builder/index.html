Grading rubric for any assignment

Build a clear analytic rubric with criteria, performance levels and descriptions students can understand, plus a feedback comment bank.

Published
November 20, 2026
Works with
ChatGPT, Claude and Gemini
Level
Intermediate
By
GoodAIPromt editorial team

Rubrics make grading faster and fairer, and they show students what good work looks like before they start. Vague levels like "good" and "excellent" don't help anyone. This prompt writes observable descriptions for each level and a bank of feedback comments you can reuse.

The prompt

You are an experienced teacher and assessment expert. Create a grading rubric.

Assignment description: 
Subject and level: 
Learning objectives being assessed: 
Number of performance levels: 
Total points and any weighting: 

Create:
1. 4–6 criteria linked to the objectives, with their weight.
2. A rubric table: criteria as rows, levels as columns. Each cell describes what the work looks like at that level in observable terms (what is present or missing), not just adjectives.
3. A student-friendly version in simpler language.
4. A feedback comment bank: 2 comments per criterion per level, specific and actionable.
5. A short self-check list students can use before submitting.

Make sure levels are clearly different from each other and points add up correctly.

0 of 5 blanks filled

How to use it

  1. Share the student version when you set the assignment.
  2. Test the rubric on two or three sample pieces and adjust unclear cells.
  3. Use the comment bank to speed up written feedback.

Tips

  • Fewer criteria are easier to apply consistently.
  • Ask students to grade an example with the rubric to build understanding.

Frequently asked questions

What does this prompt do?

Build a clear analytic rubric with criteria, performance levels and descriptions students can understand, plus a feedback comment bank.

Which AI tools does it work with?

It is written for ChatGPT, Claude and Gemini. It also works in other AI tools that accept text prompts, with small changes.

What do I need to fill in?

5 blanks: what students must produce; subject, grade or course level; objectives; e.g. 4: exceeds, meets, approaching, beginning; points. Click each blue blank on the page, type your details and press Copy prompt.

Is this prompt free to use?

Yes. You can copy and use it for personal and commercial work.
