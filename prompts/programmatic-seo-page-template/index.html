Programmatic SEO page template that adds value

Plan a scalable page template for many similar keywords, with the data each page needs so pages are useful and not thin duplicates.

Published
November 21, 2026
Works with
ChatGPT, Claude and Gemini
Level
Advanced
By
GoodAIPromt editorial team

Programmatic SEO creates many pages from one template and a dataset — for example "[tool] integrations" or "[service] in [city]". Done badly, it produces thousands of near-identical thin pages that search engines ignore. This prompt plans the keyword pattern, the data each page needs to be unique and useful, and quality rules before you build anything.

The prompt

You are an SEO strategist experienced in programmatic SEO. Plan a scalable page template.

Website and what we offer: 
Keyword pattern I'm considering (with examples): 
Data we have or can collect for each page: 
Approximate number of pages: 

Do this:
1. Assess the pattern: search intent, whether each variation needs a different answer, and the risk of thin or duplicate content.
2. Design the page template: sections in order, which data field fills each section, and which parts must be unique per page.
3. List the minimum data per page to be useful, and a rule for not publishing pages that lack it.
4. Write title, H1 and meta description patterns with variables in {CURLY BRACES}.
5. Plan internal linking between pages and from hub pages.
6. A rollout plan: start with a small test batch, what to measure, and when to scale or stop.
7. One fully written sample page for .

Be honest if the pattern is a poor fit for programmatic pages.

0 of 5 blanks filled

How to use it

  1. Start with a pattern where each variation has real differences in data or answer.
  2. Publish a test batch of 20–50 pages and check indexing and traffic before scaling.
  3. Review a random sample regularly for quality and accuracy.

Tips

  • Unique data (prices, specs, reviews, local details) is what makes these pages worth ranking.
  • Noindex or remove pages that get no impressions after a few months.

It is written for ChatGPT, Claude and Gemini. It also works in other AI tools that accept text prompts, with small changes.

What do I need to fill in?

5 blanks: site; pattern, e.g. "best crm for {industry}"; data sources; number; example variation. Click each blue blank on the page, type your details and press Copy prompt.
