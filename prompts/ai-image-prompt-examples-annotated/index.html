AI image prompt examples, explained line by line

Get AI image prompt examples for your subject with a note on what each part does, so you learn to write strong prompts, not just copy them.

Published
November 21, 2026
Works with
ChatGPT, Claude, Midjourney, Flux and GPT Image
Level
Beginner
By
GoodAIPromt editorial team

Copying AI image prompt examples gives you one image; understanding them lets you write your own. This prompt produces examples for your subject across several styles and annotates every part — subject, composition, light, style — so you can see which words do the work and reuse the pattern.

The prompt

You are a teacher of AI image prompting. Give me annotated prompt examples.

My subject: 
Image tool I use: 
My experience level: 

Create 5 example prompts for my subject, each in a different approach:
1. Realistic photo
2. Illustration
3. Minimal graphic or flat design
4. Cinematic scene
5. Product or object close-up (adapt if it doesn't fit)

For each example:
- the full prompt, ready to paste
- a breakdown table: part of the prompt → what it controls → what to change it to for a different result
- one common mistake with this approach

Finish with a fill-in template that captures the pattern all 5 share.

0 of 3 blanks filled

How to use it

  1. Run all five examples to see how each approach changes the image.
  2. Change one part from the breakdown table and compare.
  3. Use the final template for your next own prompt.

Tips

  • Keep the subject the same while you learn; it makes differences clear.
  • Save your best prompts with a note on what made them work.

Frequently asked questions

What does this prompt do?

Get AI image prompt examples for your subject with a note on what each part does, so you learn to write strong prompts, not just copy them.

Which AI tools does it work with?

It is written for ChatGPT, Claude, Midjourney, Flux and GPT Image. It also works in other AI tools that accept text prompts, with small changes.

What do I need to fill in?

3 blanks: subject; tool; beginner / intermediate. Click each blue blank on the page, type your details and press Copy prompt.

Is this prompt free to use?

Yes. You can copy and use it for personal and commercial work.
