Write a clear SOP from a messy process

Turn rough notes, a voice transcript or a long chat about how a task is done into a step-by-step standard operating procedure with checks.

Published
November 20, 2026
Works with
ChatGPT, Claude and Gemini
Level
Beginner
By
GoodAIPromt editorial team

Most processes live in one person's head, so things break when they're away. Writing an SOP feels like a chore, but you already have the raw material: notes, a recorded walkthrough or a long chat thread. This prompt turns it into numbered steps anyone can follow.

The prompt

You are an operations manager. Turn my notes into a standard operating procedure.

Process name: 
Who will follow it: 
Tools and systems used: 
Raw notes, transcript or description of how it's done today: 

Write the SOP with:
1. Purpose (one sentence) and when to use it.
2. Before you start — access, files and information needed.
3. Numbered steps. Each step starts with a verb, has one action, and names the tool or screen. Add sub-steps where needed.
4. Quality checks — how to know each key step was done right.
5. Common mistakes and how to fix them.
6. Who to contact if something goes wrong.
7. Owner and review date placeholders.

Keep wording simple. If my notes skip a step or are unclear, add a {QUESTION} marker in that spot instead of guessing.

0 of 4 blanks filled

How to use it

  1. Record yourself doing the task and paste the transcript as notes.
  2. Answer the {QUESTION} markers and ask for an updated version.
  3. Have a new person follow it and fix where they get stuck.

Tips

  • Add screenshots next to tricky steps.
  • Ask for a one-page checklist version for daily use.

Frequently asked questions

What does this prompt do?

Which AI tools does it work with?

It is written for ChatGPT, Claude and Gemini. It also works in other AI tools that accept text prompts, with small changes.

What do I need to fill in?

4 blanks: process; role and experience level; tools; notes. Click each blue blank on the page, type your details and press Copy prompt.

Yes. You can copy and use it for personal and commercial work.
