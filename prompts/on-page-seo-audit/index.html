On-page SEO audit for a single page

Check one page's title, headings, content, internal links, images and search intent match, and get a prioritised list of fixes.

Published
November 20, 2026
Works with
ChatGPT, Claude and Gemini
Level
Intermediate
By
GoodAIPromt editorial team

Full site audits produce hundreds of warnings, but often one important page just needs a focused check. This prompt reviews a single page against its target keyword: does it match search intent, cover the topic and give search engines clear signals? You get fixes ranked by impact.

The prompt

You are an SEO consultant. Audit this page.

URL and target keyword: 
Secondary keywords: 
What currently ranks for the keyword (titles or page types, if known): 
Page HTML or content, including title tag, meta description and headings: 

Check and comment on:
1. Search intent match — does the page type and angle fit what searchers want?
2. Title tag and meta description — length, keyword, appeal. Suggest 3 alternatives.
3. Headings — one H1, logical H2/H3 structure, keyword use.
4. Content — coverage of subtopics, depth, freshness, readability, missing questions.
5. Internal links — in and out, anchor text; suggest 3–5 links.
6. Images — alt text, file names, size hints.
7. Structured data opportunities.
8. Calls to action and user experience issues visible in the content.

Finish with a table of fixes: issue, fix, impact (high/medium/low), effort (low/medium/high), sorted by impact.

0 of 4 blanks filled

How to use it

  1. Paste the full page content, not just the visible text.
  2. Look at the top results yourself to confirm intent.
  3. Make high-impact fixes first and track rankings for 4–8 weeks.

Tips

  • Run it on pages that rank on page two — they often gain the most.
  • Ask for a rewritten introduction if intent doesn't match.
