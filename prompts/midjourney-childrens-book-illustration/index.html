Midjourney children's book illustration

Create warm, consistent children's book illustrations with a chosen art style, character description and page layout space for text.

Published
November 20, 2026
Works with
Midjourney, GPT Image and Flux
Level
Intermediate
By
GoodAIPromt editorial team

Picture books need illustrations that feel gentle, stay consistent from page to page and leave room for text. This prompt describes the character in fixed detail and the scene separately, so you can reuse the character description across every page of your story.

The prompt

Children's picture book illustration, , warm and gentle mood.
Main character: .
Scene: .
Setting: .
Composition: character in the  third, clear facial expression showing , simple uncluttered background, soft light, large empty area at the  for story text.
Palette: . Friendly rounded shapes, age-appropriate for  readers, no text in the image.

0 of 9 blanks filled

How to use it

  1. Write the character description once and paste it unchanged for every page.
  2. Change only the scene, setting and emotion for each new page.
  3. Use character reference features in your tool to keep the look consistent.

Tips

  • In Midjourney, add --ar 3:2 for spreads and use --cref with your first good image of the character.
  • Check that the empty text area is big enough before choosing a final image.

Frequently asked questions

What does this prompt do?

Create warm, consistent children's book illustrations with a chosen art style, character description and page layout space for text.

Which AI tools does it work with?

It is written for Midjourney, GPT Image and Flux. It also works in other AI tools that accept text prompts, with small changes.

What do I need to fill in?

9 blanks: art style, e.g. soft watercolour and coloured pencil; character description — species or age, clothes, colours, one distinctive feature; what happens on this page, e.g. the character finds a tiny door in an old tree; place and time of day; left or right; emotion; and more. Click each blue blank on the page, type your details and press Copy prompt.

Is this prompt free to use?

Yes. You can copy and use it for personal and commercial work.
