# Promt — сайт с промтами для нейросетей

Каждый день на сайте появляется новый промт. Сайт собирается из файлов в `content/prompts/` и автоматически выкладывается на ваш сервер через GitHub Actions.

```
Claude (каждый день) → новый файл в GitHub → GitHub Actions собирает сайт → загружает на сервер
```

## Подключение сервера (один раз, примерно 15 минут)

### 1. Арендуйте сервер (VPS)
Подойдёт самый простой тариф: 1–2 ядра, 1–2 ГБ памяти, система **Ubuntu 24.04**. Это примерно $4–6 в месяц, например Hetzner, DigitalOcean, Timeweb или местный хостинг.
После оплаты вы получите **IP-адрес** и **пароль root**.

### 2. Запустите скрипт настройки
Подключитесь к серверу из терминала (Windows: PowerShell, Mac: Terminal):

```bash
ssh root@ВАШ_IP
```

Затем выполните на сервере:

```bash
curl -fsSL https://raw.githubusercontent.com/denovich1988-lab/promt/main/server/setup.sh -o setup.sh
bash setup.sh
```

Если у вас есть домен и он уже указывает на IP сервера (A-запись), запустите так, и HTTPS настроится сам:

```bash
bash setup.sh вашдомен.com ваша@почта.com
```

Скрипт установит nginx, создаст пользователя для деплоя и в конце выведет **IP и ключ**.

### 3. Добавьте данные в GitHub
Откройте репозиторий → **Settings → Secrets and variables → Actions**.

Во вкладке **Secrets** (кнопка «New repository secret»):

| Name | Value |
|------|-------|
| `SSH_HOST` | IP сервера |
| `SSH_USER` | `deploy` |
| `SSH_KEY` | ключ, который вывел скрипт: весь текст от `-----BEGIN` до `-----END ...-----` включительно |

Во вкладке **Variables**:

| Name | Value |
|------|-------|
| `SITE_URL` | `http://ВАШ_IP` или `https://вашдомен.com` |

### 4. Запустите первый деплой
Откройте **Actions → Build and deploy → Run workflow**. Через минуту сайт появится по адресу из `SITE_URL`.

Дальше всё работает само: каждое изменение в репозитории автоматически попадает на сервер.

## Для разработки

```bash
npm install
npm run build   # собрать сайт в dist/
npm run serve   # открыть локально: http://localhost:4321
```

Как устроены файлы промтов, описано в `CLAUDE.md`.
