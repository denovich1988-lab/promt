You don't need to pay to learn AI well. These free courses come from the companies that build AI models and from respected education projects. We picked a mix for beginners, professionals and developers.

Course catalogues change often. Everything below could be started for free when we checked; some providers sell certificates or extras separately.

## For everyone (no coding)

| Course | Provider | What you learn |
|---|---|---|
| [Claude Academy](https://academy.claude.com) | Anthropic | Using Claude well, AI fluency, Claude Code, MCP and the API — from beginner to developer |
| [OpenAI Academy](https://academy.openai.com) | OpenAI | Using ChatGPT at work, AI foundations, agents and workflows |
| [Elements of AI](https://www.elementsofai.com) | University of Helsinki & MinnaLearn | What AI is, what it can and can't do, in plain language |

## For developers

| Course | Provider | What you learn |
|---|---|---|
| [Short courses](https://www.deeplearning.ai/short-courses/) | DeepLearning.AI | Focused 1–2 hour courses on prompt engineering, agents, RAG and more |
| [Hugging Face Learn](https://huggingface.co/learn) | Hugging Face | Open models, transformers, agents and fine-tuning |
| [Practical Deep Learning for Coders](https://course.fast.ai) | fast.ai | Deep learning by building real projects |
| [Machine Learning Crash Course](https://developers.google.com/machine-learning/crash-course) | Google | Core machine learning concepts with exercises |
| [Generative AI for Beginners](https://github.com/microsoft/generative-ai-for-beginners) | Microsoft | Lessons on building generative AI apps |
| [Kaggle Learn](https://www.kaggle.com/learn) | Kaggle | Short, hands-on courses in Python, ML and data |

## Where to start

- **You use AI for everyday work:** begin with Claude Academy or OpenAI Academy, then practise with our [prompt library](/prompts/).
- **You want to understand AI, not just use it:** Elements of AI.
- **You build software:** DeepLearning.AI short courses first, then Hugging Face or fast.ai.

## Learn by doing

Courses help, but the fastest way to improve is practice. Read our guide on [how to write AI prompts](/blog/how-to-write-ai-prompts/), try the [prompt generator](/prompt-generator/), and use a ready-made prompt for a real task today.
