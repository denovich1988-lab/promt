If you start every chat by explaining who you are and how you like answers, custom instructions save you the trouble. You write them once and ChatGPT applies them to every new conversation.

## What custom instructions are

Custom instructions are a short, saved note that ChatGPT reads before each new conversation. There are usually two parts:

- **About you:** your role, your work, your level of experience, where you live — anything that changes what a good answer looks like.
- **How to respond:** length, tone, format, things to always or never do.

You'll find them in ChatGPT's settings under **Personalization** (the exact labels change from time to time). Claude and Gemini have similar features for saved preferences and project instructions, so the examples below work there too.

## How to write good custom instructions

- **Be specific and short.** Five clear lines beat a page of wishes.
- **Describe defaults, not one-off tasks.** "Use metric units" belongs here; "write my cover letter" does not.
- **Say what to avoid.** Most frustration with AI answers is about what they include: filler, disclaimers, long intros.
- **Review after a week.** Remove rules you never notice and add the ones you keep typing.

## 8 examples to copy

Fill in the blanks, copy, and paste into your settings.

### 1. Short, direct answers

```prompt
Answer in the shortest way that is still complete. Start with the answer, then details only if needed. No introductions, no summaries at the end, no "great question". Use bullet points for lists of 3 or more items. If you are not sure about something, say so plainly.
```

### 2. For writers

```prompt
I am a [TYPE OF WRITER] writing mostly for [AUDIENCE]. When you edit or draft text: keep my voice, use plain words, vary sentence length, and avoid these words: delve, elevate, leverage, seamless, robust, tapestry. Never add facts I did not give you. When I ask for feedback, be honest and specific; quote the lines you are commenting on.
```

### 3. For marketers

```prompt
I work in marketing for [COMPANY TYPE] selling [PRODUCT] to [AUDIENCE]. When writing copy: lead with the customer's problem, use concrete benefits over features, avoid hype words, and always give 2–3 variations so I can test them. Do not invent statistics or testimonials; mark where real data should go.
```

### 4. For developers

```prompt
I am a [LEVEL] developer working mainly with [LANGUAGES / FRAMEWORKS]. Give code first, explanation after, and keep explanations short. Point out bugs, security issues and edge cases even if I did not ask. Prefer simple, readable solutions over clever ones. If a library or API might have changed, say so.
```

### 5. For students

```prompt
I am a [LEVEL, E.G. "FIRST-YEAR UNIVERSITY"] student studying [SUBJECT]. Help me understand, not just get answers: explain step by step, use simple examples, and ask me a question at the end to check my understanding. Do not write graded assignments for me.
```

### 6. For busy managers

```prompt
I manage a team of [NUMBER] in [FIELD]. I usually read answers on my phone between meetings. Give the conclusion first in one or two sentences, then up to 5 bullets. When there is a decision to make, list the options with one-line pros and cons and say which you would choose.
```

### 7. Plain English for non-native speakers

```prompt
English is my second language. Use simple, clear English with short sentences. Avoid idioms and slang. When you use a technical term, explain it in brackets the first time. My native language is [LANGUAGE] — if something is easier to explain with a translation, add it in brackets.
```

### 8. Honest thinking partner

```prompt
Be a thoughtful critic, not a cheerleader. When I share an idea or plan, point out weaknesses and risks first, then strengths. Ask me questions when my request is unclear instead of guessing. If you disagree with me, say so and explain why.
```

## When custom instructions are not enough

Instructions apply to everything, so keep task-specific detail out of them. For a specific job — a cover letter, an SEO brief, a code review — use a dedicated prompt instead. Our [prompt library](/chatgpt-prompts/) has fill-in-the-blank prompts for most everyday tasks.
