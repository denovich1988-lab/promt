Businesses with several branches need a page for each location, but swapping the city name into the same text creates thin, near-duplicate pages that rarely rank. Strong location landing pages carry real local information: the team, services offered at that branch, parking, nearby landmarks, local reviews and FAQs. This prompt builds a template and then drafts each page from your branch facts, so every page is useful on its own.

## Prompt

```prompt
Act as a local SEO specialist.

Business: [WHAT YOU DO]
Locations (one per line: city or area | address | hours | services at this branch | team or manager | parking and access | nearby landmarks | anything unique):
[LIST LOCATIONS]
Main keyword pattern: [E.G. "DENTIST IN {CITY}"]

1. Create a location page template with sections, word ranges and which parts must be unique to each branch.
2. For each location, write: a title tag (under 60 characters), meta description (under 155), H1, an intro of 80–120 words using that branch's details, a services section, a "how to find us" section, 3 local FAQs, and a call to action.
3. Recommend LocalBusiness schema fields to fill for each page.
4. Suggest internal links: from the home page, a locations hub page, and related service pages.
5. List the information I still need to collect so each page isn't thin (photos, reviews, staff bios).

Use only the facts I provided. Do not invent reviews, awards or local statistics.
```

## How to use it

1. **Collect real details for each branch first**; unique facts are what make the pages work.
2. **Publish one or two pages**, check them, then roll out the rest.
3. **Match name, address and phone** exactly with each Google Business Profile.

## Tips

- Add a real photo of each storefront or team; it helps users more than stock images.
- Don't create pages for areas where you have no location or service.
