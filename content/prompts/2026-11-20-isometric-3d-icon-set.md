Icons only look professional when they clearly belong to one set — same angle, materials and light. Generating them one by one with different prompts produces a mismatched mix. This prompt fixes the style once and changes only the object, so every icon fits.

## Prompt

```prompt
Isometric 3D icon of [OBJECT, E.G. A SHIELD WITH A CHECKMARK], centred on a plain [BACKGROUND COLOUR] background.
Fixed style for the whole set: 30° isometric angle, soft rounded shapes, [MATERIAL, E.G. MATTE CLAY WITH SUBTLE GLOSSY HIGHLIGHTS], main colour [PRIMARY COLOUR] with [ACCENT COLOUR] details, soft studio lighting from the top left, gentle shadow directly underneath.
Simple and readable at small sizes, minimal detail, no text, no outline, high resolution, 1:1 aspect ratio.
```

## How to use it

1. **Keep everything after "Fixed style" identical** for every icon.
2. **Change only the object** — for example cloud, lock, chart, rocket.
3. **Remove backgrounds** and export as PNG at the sizes you need.

## Tips

- In Midjourney, reuse the same `--sref` image and seed for better consistency.
- Generate a few extra and keep only the best-matching set.
