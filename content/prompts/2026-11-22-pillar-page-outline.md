A pillar page covers a broad topic well and links out to detailed articles on each subtopic, which helps both readers and search engines understand how your content fits together. This ChatGPT prompt outlines a pillar page for your main keyword: the sections it needs, which cluster articles each section should link to, anchor text ideas, and the questions it should answer.

## Prompt

```prompt
You are an SEO content strategist planning a pillar page.

Website and audience: [WEBSITE AND AUDIENCE]
Pillar topic and main keyword: [PILLAR KEYWORD]
Existing articles on related subtopics (title + URL): [EXISTING ARTICLES]
Related keywords and questions from my research: [KEYWORDS AND QUESTIONS]
Business goal of the page: [GOAL, e.g. newsletter signups, demo requests]

Create:
1. A page title, H1 and meta description for the pillar page.
2. A full outline with H2s and H3s that covers the topic from basics to advanced, each with 1–2 lines on what to write.
3. For each H2, the cluster article it should link to (from my list), or a new cluster article to create (title + target keyword).
4. Anchor text ideas for each internal link, varied and descriptive.
5. A list of questions to answer in an FAQ section.
6. Where to place the call to action for my goal.
7. Which cluster articles should link back to the pillar, and suggested sentences for those links.
Do not repeat the same anchor text twice.
```

## How to use it

1. **List every related article you already have**, even old ones.
2. **Write the missing cluster articles** first, then the pillar.
3. **Add the links back from cluster articles** on the day the pillar goes live.
