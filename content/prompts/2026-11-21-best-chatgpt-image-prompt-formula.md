The best ChatGPT image prompts read like a brief to a designer, not a list of keywords. ChatGPT's image model follows full sentences well, can place exact text and supports editing in follow-up messages — so a clear structure matters more than magic words. This formula covers what the model needs in one message and tells it how to handle the second round of edits.

## Prompt

```prompt
Create an image with these specifications.

Purpose: [WHAT THE IMAGE IS FOR, e.g. hero image for a meditation app landing page]
Main subject: [SUBJECT, described specifically — age, material, color, pose, expression]
Scene and background: [SCENE]
Composition: [FRAMING, e.g. subject on the left third, empty space on the right for a headline]
Style: [STYLE, e.g. soft 3D render / editorial photo / flat vector / watercolor]
Lighting and color palette: [LIGHT AND COLORS, e.g. morning light, sage green and cream]
Text in the image (exact wording, or "none"): "[EXACT TEXT]"
Text placement and font feel: [PLACEMENT AND FONT]
Aspect ratio: [1:1 / 3:2 / 2:3 / 16:9 / 9:16]
Avoid: [THINGS TO AVOID, e.g. extra hands, clutter, logos, watermarks]

Before generating, restate the brief in 2 lines so I can confirm nothing is misunderstood. After generating, suggest 3 specific edits that could improve it.
```

## How to use it

1. **Fill in purpose and composition first** — they decide layout more than style does.
2. **Put exact text in quotes**, and keep it short (a headline, not a paragraph).
3. **Edit in small steps**: "keep everything, change only the background to dusk".

## Tips

- Upload a reference image and say which parts to copy (palette, layout) and which to ignore.
- If text comes out wrong, ask the model to regenerate only the text, letter by letter.
