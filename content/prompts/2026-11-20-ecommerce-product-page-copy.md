Many product pages reuse the manufacturer's description, which is thin and duplicated across hundreds of stores. Shoppers need to know quickly what the product does for them and whether it fits. This prompt writes unique copy around a target keyword, structured for both scanning and search.

## Prompt

```prompt
You are an ecommerce copywriter with SEO skills. Write a product page.

Product name: [NAME]
Target keyword: [KEYWORD SHOPPERS SEARCH]
Product facts (materials, size, features, what's in the box): [FACTS]
Who it's for and the main use: [CUSTOMER AND USE]
What makes it different from similar products: [DIFFERENCES]
Brand tone: [TONE]

Write:
1. SEO title (under 60 characters) and meta description (under 155 characters), both including the keyword naturally.
2. H1 product name line.
3. Opening paragraph (2–3 sentences): who it's for and the main benefit.
4. 5 benefit bullets, each starting with the benefit and ending with the feature that delivers it.
5. A "Details" section with specs in a table.
6. A short "How to use / care" section if relevant.
7. 4 FAQs a shopper might ask before buying.

Rules: only use the facts provided; no invented claims, awards or numbers. If a key fact is missing (e.g. size), add {ADD: fact} instead of guessing.
```

## How to use it

1. **Paste the full spec sheet** into the facts field.
2. **Replace every {ADD} marker** before publishing.
3. **Add real customer photos and reviews** near the bullets if you have them.

## Tips

- Write unique copy for each variant page only if the variants really differ.
- Ask for an alt text for each product image at the end.
