A personal cheat sheet of ChatGPT prompt templates saves time and gets more consistent results than writing prompts from scratch. The core pattern is simple — role, task, context, format, checks — but it works best when filled in for the tasks you actually do. This prompt builds that cheat sheet for your job.

## Prompt

```prompt
Build me a personal cheat sheet of prompt templates.

My role: [ROLE]
Tasks I use AI for most often (5–10): [TASKS]
Tools I use: [CHATGPT / CLAUDE / GEMINI]
Usual output formats I need: [E.G. "EMAILS, TABLES, SLIDES OUTLINES"]

For each task, write a template with these parts:
- Role: who the AI should act as
- Task: one clear instruction
- Context: the [BLANKS] I should fill in each time
- Format: length, structure, tone
- Checks: what the AI must verify or ask before answering

Then add:
1. 5 general follow-up prompts (e.g. "make it shorter", "what am I missing?", "argue against this").
2. 3 common mistakes in my templates to avoid.
Format the whole thing as a one-page cheat sheet I can save.
```

## How to use it

1. **List the tasks you repeat weekly**, not one-off ones.
2. **Save the cheat sheet** where you can copy from it quickly.
3. **Update a template** whenever you improve a prompt in a real chat.

## Tips

- Blanks in [BRACKETS] remind you which context to add each time.
- The checks line is what stops confident but wrong answers.
