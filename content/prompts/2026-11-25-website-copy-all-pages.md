Writing website copy one page at a time leads to mixed tones, repeated claims and missing calls to action. This ChatGPT prompt for website copy plans the whole small site first, so each page has a clear job, then drafts the copy page by page in one voice. It uses only the facts you provide, leaving placeholders where you need proof, prices or details.

## Prompt

```prompt
Write the copy for a small business website.

Business name and what we do: [DESCRIPTION]
Location or service area: [AREA]
Ideal customers and their main problem: [AUDIENCE]
Services or products (with key details): [LIST]
What makes us different (facts only): [DIFFERENTIATORS]
Proof we can show: [REVIEWS, YEARS, CERTIFICATIONS — or "none yet"]
Tone: [e.g. friendly and plain, premium, technical]
Main action we want visitors to take: [CALL / BOOK / QUOTE / BUY]
Pages needed: [e.g. Home, About, Services, one page per service, Contact]

1. Site plan: each page's single job, main keyword idea and CTA.
2. Copy for each page with H1, short intro, section headings and body, CTA lines.
3. For each page: an SEO title (max 60 characters) and meta description (max 155 characters).
4. A short list of places where I must add real details, marked {ADD: ...}.

Rules: write for customers, not about ourselves; short sentences; no invented reviews, numbers or awards; no hype words.
```

## How to use it

1. **List real differentiators** — the copy can only be as specific as your facts.
2. **Fill every {ADD: ...} marker** before publishing.
3. **Read each page aloud**; cut any sentence a customer wouldn't care about.

## Tips

- Generate the Home page last if you're unsure; it's easier once service pages exist.
- Add customer quotes you've actually received in place of generic praise.
