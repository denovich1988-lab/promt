In paid social, the creative (the hook, angle and format) often matters more than audience settings. Testing random ads teaches little; testing one variable at a time shows which angle actually sells. This prompt builds a creative testing plan with angles drawn from customer language, variant briefs for each, a simple budget split and rules for when to scale or stop.

## Prompt

```prompt
Create an ad creative testing plan for paid social.

Product and offer: [OFFER]
Platform(s): [e.g. Facebook and Instagram, TikTok, LinkedIn]
Audience: [AUDIENCE]
Customer language (reviews, survey answers, comments): [PASTE QUOTES]
Current best ad and its results, if any: [AD + METRICS]
Test budget per week: [BUDGET]
Main metric: [e.g. cost per purchase, cost per lead]

1. 5 angles to test (e.g. pain, outcome, objection, comparison, social proof), each based on a customer quote I gave.
2. For the 2 strongest angles: 3 hooks each (first 3 seconds or first line) and a brief per variant: format (static, carousel, short video, UGC style), visual, primary text, headline.
3. Test structure: what changes and what stays fixed in each round; round 1 tests angles, round 2 tests hooks, round 3 tests formats.
4. Budget split and minimum spend or results before judging a variant.
5. Decision rules: when to pause, iterate or scale. Note the platform's learning phase.
6. A simple results log template.

Don't invent results or claims; use only proof I provided.
```

## How to use it

1. **Paste real customer words** — angles built on them usually beat brainstormed ones.
2. **Change one variable per round** so results are clear.
3. **Log every test** to build a library of winning angles.

## Tips

- Refresh winning ads with new hooks before performance drops.
- Check each platform's ad policies before launching health, finance or before/after claims.
