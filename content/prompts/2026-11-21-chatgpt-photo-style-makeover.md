Most ChatGPT prompts for photos fail in the same way: the new style is nice, but the face or product changes too. This prompt separates what must stay locked from what the style may change, then asks for several style options so you can pick one and refine it.

## Prompt

```prompt
I uploaded a photo. Restyle it, but keep the subject faithful.

Must stay the same: [FACE, POSE, CLOTHES, PRODUCT DETAILS, LOGOS, ETC.]
Photo is for: [USE, E.G. "PROFILE PICTURE", "WALL PRINT", "SHOP BANNER"]

Make [NUMBER] versions, one per style:
1. [STYLE 1, E.G. "1970S 35MM FILM, WARM GRAIN"]
2. [STYLE 2, E.G. "CLEAN STUDIO PORTRAIT, SOFT GREY BACKDROP"]
3. [STYLE 3, E.G. "OIL PAINTING WITH VISIBLE BRUSHSTROKES"]

For every version:
- keep the same framing and aspect ratio as the original unless I say [NEW ASPECT RATIO]
- adjust light and colour to suit the style, not the person's features
- no added text, watermarks or extra people

After the images, write one line per version on what changed, so I can ask for tweaks.
```

## How to use it

1. **List exactly what must not change**; this is what keeps the person or product recognisable.
2. **Pick up to three styles** that fit where the photo will be used.
3. **Choose the best version and refine it** in the same chat with one change per message.

## Tips

- If faces drift, ask for a single style per message instead of three at once.
- Mention the final use; a wall print needs different framing than a round profile picture.
