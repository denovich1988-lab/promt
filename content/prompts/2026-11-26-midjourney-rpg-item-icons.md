Indie game developers need dozens of item icons for inventories, shops and loot drops, and they all need to look like they belong to the same game. AI images often vary in angle, lighting and background between generations. These Midjourney game item icon prompts lock down the style, framing and background so you can produce a consistent set of weapons, potions, armor and loot, ready to clean up and import into your engine.

## Prompt

```prompt
Game item icon of [ITEM, E.G. A GLOWING BLUE HEALTH POTION IN A ROUND FLASK / AN ENCHANTED IRON SWORD WITH RUNES / A LEATHER SATCHEL OF GOLD COINS / A DRAGON SCALE SHIELD], single object centred, three-quarter view, [STYLE, E.G. HAND-PAINTED FANTASY / CLEAN CEL-SHADED / PIXEL-ART INSPIRED / SEMI-REALISTIC 3D RENDER], bold readable silhouette, strong rim light from the top left, subtle [RARITY COLOUR, E.G. PURPLE] magical glow for [RARITY, E.G. EPIC] rarity, plain [BACKGROUND, E.G. FLAT DARK GREY / SOLID WHITE] background, no text, no frame, no hands, consistent game asset style, high detail at small sizes --ar 1:1 --style raw --v 7
```

## How to use it

1. **Keep the style, angle, light and background text identical** for every item in the set.
2. **Use one approved icon as a style reference** (e.g. `--sref`) for the next ones.
3. **Remove the background and resize** to your engine's icon size, then check readability at that size.

## Tips

- Use rarity colours consistently (common grey, rare blue, epic purple) across the set.
- Check your AI tool's licence terms before using images commercially in a game.
