The best Midjourney prompts combine a clear description with parameters chosen on purpose: aspect ratio for the use, stylize for how artistic it gets, chaos for variety. Many people copy parameters without knowing what they change. This prompt picks settings for your subject and explains each one. Check current parameter names in Midjourney's docs, as they can change between versions.

## Prompt

```prompt
You are a Midjourney expert. Write prompts for my subject and choose parameters on purpose.

Subject: [SUBJECT]
Use: [USE, E.G. "PHONE WALLPAPER", "BLOG HEADER", "PRINT"]
Look I want: [LOOK, E.G. "PHOTOREAL", "PAINTERLY", "GRAPHIC POSTER"]
Do I want variety or consistency right now: [EXPLORE / REFINE]
Things to exclude: [EXCLUDE]

Give me:
1. A main prompt: subject first, then setting, composition, light, style and colour, in natural sentences.
2. Parameters with one line each on why: aspect ratio (--ar), stylize (--s), chaos (--c), --no for exclusions, and raw style if photoreal.
3. An "explore" version with higher chaos and a "refine" version with low chaos.
4. 3 short swaps (light, lens or palette) to try next.
5. A note on which current Midjourney version features to double-check in the docs.
```

## How to use it

1. **Start with the explore version** to see different directions.
2. **Switch to the refine version** once you like a direction.
3. **Change one parameter at a time** so you learn what each does.

## Tips

- Use --ar that matches where the image will appear.
- Write the exclusion list short; too many --no terms can backfire.
