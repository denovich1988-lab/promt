Service businesses often create one page per city by swapping the town name. Search engines treat those as thin, near-duplicate pages. This prompt writes each location page around real local details you supply — jobs done there, common problems, travel times — so every page is useful on its own.

## Prompt

```prompt
You are a local SEO copywriter. Write a service area page.

Business and main service: [BUSINESS AND SERVICE]
Location for this page: [CITY OR AREA]
Real local details (jobs done there, landmarks, common local problems, response time, local regulations): [LOCAL DETAILS]
Target keyword: [E.G. "SERVICE IN CITY"]
Contact details and call to action: [CTA]

Write:
1. An SEO title (under 60 characters) and meta description (under 155).
2. An H1 and a 2-sentence intro that mentions the area naturally.
3. A section on the problems customers in this area typically face, using only the details I gave.
4. "How we work in [CITY OR AREA]": process, response time, service radius.
5. A short list of nearby neighbourhoods we cover.
6. 3 FAQs specific to this location.
7. A closing call to action.

Do not invent reviews, addresses or projects. If my local details are thin, list what I should collect to make the page unique.
```

## How to use it

1. **Collect 3–5 genuine local facts** per city before you run the prompt.
2. **Run it once per location** with different details each time.
3. **Link each page** from your main service page and your Google Business Profile.

## Tips

- Add a real photo from a job in that area to each page.
- Only create pages for areas you actually serve.
