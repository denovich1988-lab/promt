Building slides from a blank deck usually leads to walls of text. A better approach is to plan the story first, one message per slide, then design. This ChatGPT prompt for a PowerPoint presentation creates a slide-by-slide outline with action titles, a few supporting points, a visual suggestion and speaker notes, so you can build the deck in any tool quickly.

## Prompt

```prompt
Create a slide-by-slide outline for a presentation.

Topic: [TOPIC]
Audience and what they already know: [AUDIENCE]
Goal (what they should think or do afterwards): [GOAL]
Length: [MINUTES] — about [N] slides
Setting: [LIVE TALK / VIDEO CALL / SENT AS A FILE TO READ]
Content and data to include: [PASTE NOTES, FIGURES, LINKS]

For each slide give:
- Slide title written as the main message (a full sentence, not a label)
- 2–4 short supporting points (max 8 words each)
- A visual idea (chart type, image, diagram, or "none")
- Speaker notes (40–80 words) in a natural spoken style

Structure: opening hook, the problem or context, main points, evidence, recommendation or call to action, closing.
Also give: a one-sentence summary of the whole talk, and the 3 questions the audience will most likely ask.
Use only the data I gave; mark any number I still need to add as {ADD DATA}.
```

## How to use it

1. **Read the action titles in order** — they should tell the whole story alone.
2. **Build the slides** in PowerPoint, Google Slides or Keynote using the visual ideas.
3. **Rehearse with the speaker notes**, then shorten them to keywords.

## Tips

- For a deck sent as a file, ask for fuller text on slides and shorter notes.
- Cut any slide whose title doesn't move the story forward.
