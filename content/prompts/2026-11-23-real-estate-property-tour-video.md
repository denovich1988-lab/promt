Short property tour clips help listings stand out on social media, but AI video tools need very specific camera directions to look like a real walkthrough. This prompt describes a calm, steady tour shot by shot. Use it with photos of the real property (image-to-video) so viewers see the actual home, not an invented one.

## Prompt

```prompt
Write image-to-video prompts for a short real estate property tour.

Property type and style: [PROPERTY, e.g. modern 3-bed townhouse]
Rooms or spaces to show, in order (I will upload a photo of each): [ROOMS]
Time of day and light: [LIGHT, e.g. bright morning]
Aspect ratio: [ASPECT RATIO, e.g. 9:16 for reels]
Mood: [MOOD, e.g. calm, warm, luxury]

For each room, write one 4–5 second prompt with:
- a single smooth camera move (slow dolly forward, gentle pan, slight crane up), steady like a gimbal
- natural light coming through the windows, true colors
- no people, no objects added or removed, no change to layout, furniture or finishes
- a note on where the next shot should start for a smooth cut
Then suggest an order, total length, and on-screen text for each shot (room name, one feature).
```

## How to use it

1. **Upload clear, well-lit photos** of each room into an image-to-video tool.
2. **Generate one clip per room** and drop any that alter the property.
3. **Edit them together** with music and the on-screen text.

## Tips

- Label the clips as virtual or AI-assisted tours where local rules require it, and never show features the home doesn't have.
- Add an aerial opener with the [FPV drone flythrough video](/prompts/fpv-drone-flythrough-video/) prompt.
