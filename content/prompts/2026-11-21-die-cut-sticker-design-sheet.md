Sticker sets sell well and make great packaging extras, but they only work if every sticker looks like part of one family. Image models do this well when you describe a single style, a white die-cut border and a flat background. Use this prompt to create a set around one theme, then prepare the files for printing.

## Prompt

```prompt
A sticker sheet of [NUMBER, E.G. 6] die-cut stickers on a plain light grey background, theme: [THEME, E.G. COFFEE SHOP MORNINGS], each sticker a separate cute object: [LIST OF OBJECTS OR CHARACTERS], [STYLE, E.G. BOLD KAWAII VECTOR ILLUSTRATION WITH THICK OUTLINES], [COLOUR PALETTE, E.G. WARM BROWNS, CREAM AND PASTEL PINK], flat colours with simple shading, thick white die-cut border around each sticker, even spacing, no overlapping, [OPTIONAL TEXT, E.G. ONE STICKER WITH THE WORDS "BUT FIRST COFFEE"], clean edges, print-ready look
```

For Midjourney, add `--ar 1:1`. Use Ideogram or GPT Image if a sticker includes text, as they usually render words more reliably.

## How to use it

1. **List the objects** you want so the set has variety instead of near-duplicates.
2. **Upscale the best sheet**, then cut out each sticker and vectorise or clean edges in a design tool.
3. **Order a test print** before selling to check colours and borders.

## Tips

- Keep text to one or two short words per sticker; long text often renders wrong.
- Avoid characters, logos or styles that belong to someone else when selling merch.
