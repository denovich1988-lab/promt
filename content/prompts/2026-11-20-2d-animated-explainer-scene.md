Explainer videos use simple 2D animation to make an idea easy to follow. Each scene should explain one thing with clear visuals. This prompt describes a single scene — characters, icons, motion and colours — so you can build an explainer one shot at a time.

## Prompt

```prompt
Flat 2D motion graphics animation scene for an explainer video.
Idea this scene explains: [IDEA, E.G. HOW A CUSTOMER BOOKS AN APPOINTMENT IN THREE TAPS].
Visuals: [CHARACTERS AND OBJECTS, E.G. A SIMPLE FLAT CHARACTER HOLDING A PHONE, THREE ICONS POPPING UP ONE BY ONE].
Motion: smooth easing, elements slide and scale in, [SPECIFIC ACTION], then settle.
Background: clean [BACKGROUND COLOUR] with subtle shapes.
Style: modern flat vector illustration, rounded shapes, no gradients, consistent line weight. Brand colours: [COLOURS].
Duration [SECONDS] seconds, no text (titles will be added later), no camera shake. Aspect ratio [RATIO].
```

## How to use it

1. **Write your script first** and split it into one idea per scene.
2. **Generate each scene** with the same style and colour lines.
3. **Add voiceover and text** in your video editor.

## Tips

- Keep the style lines identical across scenes for consistency.
- Short scenes of 4–6 seconds tend to animate more cleanly.
