A manual action in Search Console can wipe out traffic, and a weak reconsideration request — vague, defensive or missing evidence — usually gets rejected. Reviewers want to see that you understood the issue, fixed it thoroughly and changed the process that caused it. This reconsideration request prompt helps you document all three clearly and honestly.

## Prompt

```prompt
Act as an SEO consultant who has handled manual action recoveries. Help me write a reconsideration request.

Manual action type and message (paste from Search Console): [TEXT]
Affected pages or site sections: [DETAILS]
What caused it, honestly: [E.G. PAID LINKS BY A FORMER AGENCY, THIN AFFILIATE PAGES, USER-GENERATED SPAM]
What I've fixed so far: [ACTIONS, NUMBERS — E.G. REMOVED 340 LINKS, DISAVOWED 120 DOMAINS, NOINDEXED 900 PAGES]
Evidence I have: [E.G. OUTREACH LOG, SPREADSHEETS, BEFORE/AFTER EXAMPLES]
Process changes made: [E.G. NEW CONTENT POLICY, MODERATION, AGENCY CONTRACT TERMS]

Do this:
1. Check whether my fixes fully address this manual action type, and list gaps to fix before submitting.
2. Write the request (under 500 words): acknowledge the issue clearly, explain the cause without blaming, list fixes with numbers, reference supporting documents, describe process changes, and close politely.
3. A list of documents to link (e.g. shared spreadsheet of removed links) and how to organise them.
4. What to do if the request is rejected.
Keep the tone factual and accountable. Don't claim fixes I haven't listed.
```

## How to use it

1. **Finish the cleanup first**; submitting early wastes a review cycle.
2. **Link evidence in shareable documents** that reviewers can open without signing in.
3. **Read Google's current documentation** for your manual action type before submitting.

## Tips

- Admitting the cause plainly works better than arguing the action was unfair.
- Recovery of rankings may take time even after the action is lifted.
