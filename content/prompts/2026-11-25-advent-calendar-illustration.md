An advent calendar illustration can be a printable family gift, a shop window poster or the base for a daily social media countdown from December 1 to 24. AI image tools can create the festive scene well, but 24 neatly numbered doors are harder, because models still make mistakes with many numbers in one image. This prompt writes a scene prompt with space for the doors, plus a matching set of small door illustrations you can arrange and number yourself.

## Prompt

```prompt
Write image prompts for an advent calendar design.

Use: [PRINTABLE CALENDAR / SHOP POSTER / DAILY SOCIAL POSTS]
Scene theme: [E.G. SNOWY VILLAGE, WINTER FOREST WITH ANIMALS, COZY HOUSE INTERIOR]
Style: [E.G. CHILDREN'S BOOK WATERCOLOUR, VINTAGE PRINT, FLAT VECTOR]
Colours: [PALETTE]
Format: [A3 PORTRAIT / SQUARE / LANDSCAPE]

1. Main scene prompt (80–120 words): a detailed festive scene with many windows, doors and small objects spread evenly across the image so 24 doors can be placed on top later, balanced composition, soft lighting, no text or numbers.
2. A style line to repeat in every prompt to keep the set consistent.
3. 24 short prompts (one line each) for small door illustrations, one per day, with simple festive objects (mitten, star, candle, sled, cocoa mug, etc.) in the same style on a plain background.
4. A version of the main scene prompt that includes only the title "[TITLE]" in quotes at the top, for tools good at text.
5. A short layout tip for placing and numbering the doors in a design tool.
```

## How to use it

1. **Generate the main scene first** and pick the strongest composition.
2. **Create the 24 door images** with the repeated style line.
3. **Add numbers in a design tool** so they are clean and correctly ordered.

## Tips

- For printing, upscale the main scene and check fine details at full size.
- For social posts, reveal one door image each day with a short message.
