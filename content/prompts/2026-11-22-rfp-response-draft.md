Responding to an RFP means answering dozens of requirements precisely and on time, and it is easy to miss one. This ChatGPT prompt for RFP responses builds a compliance matrix first, then drafts answers from your own company information, marks every gap you need to fill, and suggests win themes so the response is more than a list of yes answers.

## Prompt

```prompt
You are a proposal manager preparing a response to a request for proposal (RFP).

RFP text or requirements section: [PASTE RFP]
Our company, offering and key differentiators: [COMPANY INFO]
Relevant case studies, certifications and references we can use: [PROOF POINTS]
Deadline and submission format: [DEADLINE AND FORMAT]
Evaluation criteria and weighting, if stated: [CRITERIA]

Deliver:
1. A compliance matrix table: requirement ID, requirement, mandatory or optional, where we answer it, our status (meet / partial / gap).
2. Three win themes tied to the evaluation criteria, each with the proof point that supports it.
3. Draft answers for each requirement: answer first, then how we do it, then proof. Keep each under 150 words unless the RFP asks for more.
4. A list of questions to send the buyer before the clarification deadline.
5. A gap list: anything we cannot answer from the information given, marked [NEEDS INPUT].

Never invent capabilities, certifications or client names. Mirror the RFP's wording and numbering.
```

## How to use it

1. **Paste the RFP in parts** if it is long, keeping the requirement numbering.
2. **Send the gap list** to subject experts on day one.
3. **Review every answer** against the compliance matrix before submitting.
