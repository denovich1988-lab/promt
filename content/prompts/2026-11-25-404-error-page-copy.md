A 404 error page appears when someone follows a broken link or mistypes a URL. A bare "Page not found" message sends most of those visitors back to Google. A good 404 page explains what happened in one line, offers search and the most useful links, and matches your brand voice. This prompt writes several versions of that copy and adds a short checklist for finding and fixing the broken links that cause 404s in the first place.

## Prompt

```prompt
Act as a UX writer and technical SEO.

Website: [SITE NAME AND WHAT IT OFFERS]
Brand tone: [E.G. FRIENDLY, PLAYFUL, FORMAL]
Most useful pages for a lost visitor: [5–8 PAGES WITH URLS]
Main action I want visitors to take: [E.G. SEARCH, BROWSE PRODUCTS, CONTACT SUPPORT]

1. Write 3 versions of 404 page copy (straightforward, friendly, light humour). Each has: a headline under 8 words, one or two sentences explaining what happened without blaming the visitor, a search box label, a short list of suggested links with anchor text, and a button label.
2. Suggest a page title and note that the page should return a real 404 status code, not 200.
3. Give me a checklist to reduce 404s: where to find them (Search Console, server logs, a site crawler), when to use a 301 redirect versus leaving a 404, and how to fix internal links.
4. Suggest one way to track visits to the 404 page in analytics.
```

## How to use it

1. **List the pages that help most** when someone is lost, such as categories, popular guides or contact.
2. **Pick one copy version** and ask your developer to keep the 404 status code.
3. **Work through the checklist monthly** to fix the links that send people there.

## Tips

- Redirect only when a close replacement page exists; redirecting everything to the home page confuses users.
- Keep the 404 page light so it loads fast.
