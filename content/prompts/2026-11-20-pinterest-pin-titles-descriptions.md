Pinterest works more like a search engine than a social feed: people type what they want and save pins to come back later. Pins with clear keywords and helpful text overlays get found for months. This prompt writes several pin variations for one link, so you can test different angles.

## Prompt

```prompt
You are a Pinterest marketing specialist. Create pins for this link.

Link and what it offers: [URL AND CONTENT SUMMARY]
Audience: [AUDIENCE]
Main keyword and related search phrases: [KEYWORDS]
Brand voice: [VOICE]

Create 5 pin variations, each with a different angle (e.g. how-to, list, problem/solution, inspiration, checklist). For each:
1. Pin title (under 100 characters) with the keyword near the start.
2. Description (200–400 characters) written naturally for searchers, ending with a reason to click.
3. Text overlay for the image (max 8 words).
4. Image idea (what the visual should show).

Then:
5. 3 board names that people would search for, with a one-line board description each.
6. Alt text for each pin image.

No hashtag stuffing; at most 2–3 relevant hashtags per description.
```

## How to use it

1. **Use keywords from Pinterest's own search suggestions.**
2. **Design each pin** with the overlay text in a large, readable font.
3. **Publish variations over several weeks** rather than all at once.

## Tips

- Vertical 2:3 images tend to display best in the feed.
- Check Pinterest analytics after a month to see which angle earns saves.
