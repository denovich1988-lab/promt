Posters need text that is spelled correctly and easy to read, which many image models struggle with. Ideogram and GPT Image handle typography better, especially when the exact words are in quotes and the layout is described. This prompt keeps text short and puts it in clear zones.

## Prompt

```prompt
A [STYLE, E.G. BOLD SWISS-STYLE / RETRO 70S / MINIMAL MODERN] event poster, portrait orientation.
Top: large headline text "[EVENT NAME]" in [FONT STYLE, E.G. HEAVY CONDENSED SANS-SERIF].
Middle: [MAIN VISUAL, E.G. AN ABSTRACT ILLUSTRATION OF SOUND WAVES / A JAZZ SAXOPHONE IN FLAT SHAPES].
Bottom: smaller text "[DATE]" and "[VENUE, CITY]" on separate lines.
Colour palette: [2–3 COLOURS]. Plenty of margin around the text, strong contrast, clean grid layout.
All text spelled exactly as written, no extra words, no other text.
```

## How to use it

1. **Keep text short:** a name, a date and a place. Long sentences increase spelling errors.
2. **Put every word in quotes** exactly as it should appear.
3. **Fix small mistakes** in a design tool, and add QR codes or logos there rather than in the prompt.

## Tips

- Generate a few variations; text accuracy can vary between runs.
- Ask for a square version for social media using the same style words.
