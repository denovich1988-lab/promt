Buyers do not care what a feature is; they care what it changes for them. Many sales teams still lead with specs. These ChatGPT sales prompts translate each feature into a benefit for a specific buyer, add a proof point you can verify, and give you a one-line talk track to use on calls.

## Prompt

```prompt
You are a sales enablement coach. Turn my product features into buyer benefits.

Product: [PRODUCT]
Features (one per line):
[FEATURES]

Buyer types: [E.G. "OPERATIONS MANAGER, CFO, END USER"]
Main problems they have: [PROBLEMS]
Proof I can use (case results, reviews, demos): [PROOF]

For each feature, make a table row with:
- Feature
- What it means in plain words
- Benefit for each buyer type ("so you can…")
- Proof point from my list, or "need proof" if none fits
- One-line talk track for a sales call
- A question to ask that makes the buyer feel the problem

Then list the 3 features that matter most for each buyer type.
Do not invent results or customer names.
```

## How to use it

1. **List features in plain words**, one per line.
2. **Add real proof** — results, reviews, demos — so the benefits are believable.
3. **Practise the talk tracks** out loud and keep the ones that sound natural.

## Tips

- Use the "need proof" gaps as a list of case studies to collect.
- Lead with the problem question, then the benefit.
