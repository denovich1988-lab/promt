Chibi is a cute art style with a large head, small body and simple, expressive features, popular for profile pictures, stickers and stream emotes. AI image tools can draw chibi characters well when the prompt fixes the proportions, outfit and colours, so you can make several poses that look like the same character. This prompt writes a base chibi prompt from your description and a set of expression variations for a sticker or emote pack.

## Prompt

```prompt
Write image prompts for an original chibi-style character.

Character description: [HAIR, EYES, SKIN TONE, OUTFIT, ACCESSORIES, PERSONALITY]
Use: [PROFILE AVATAR / STICKER PACK / STREAM EMOTES]
Background: [TRANSPARENT-LOOKING PLAIN WHITE / SOFT COLOUR / SIMPLE SCENE]
Colour palette: [COLOURS]

1. Write a base prompt: chibi proportions (head about the same size as the body), big expressive eyes, simple rounded shapes, clean outlines, flat colours with soft shading, the exact outfit and colours, front-facing, full body, centred, plain background.
2. Write a short "character sheet" line I can repeat in every prompt to keep the character consistent.
3. Write 6 variation prompts for different expressions or poses (happy wave, laughing, thinking, surprised, sleepy, holding a coffee cup), each reusing the character sheet line.
4. Add things to avoid: extra fingers, realistic proportions, busy backgrounds, text, logos.

Keep the character original; do not base it on an existing anime, game or cartoon character.
```

## How to use it

1. **Describe your character in detail** once, then reuse the character sheet line.
2. **Generate the base image first** and use it as a reference image where your tool allows.
3. **Remove the background** in an editor if you need stickers or emotes.

## Tips

- Simple outfits stay more consistent across poses than detailed ones.
- For emotes, check the image still reads clearly at very small sizes.
