LinkedIn clicks are expensive, so vague ad copy wastes budget fast. This ChatGPT prompt for LinkedIn ads copy writes several versions of intro text, headlines and calls to action, each built on a different angle (pain, outcome, proof, curiosity), and keeps them within the lengths that display well in the feed.

## Prompt

```prompt
You are a B2B paid social copywriter. Write LinkedIn ad copy for this campaign.

Product or service: [PRODUCT]
Offer in the ad (demo, guide, webinar, free trial): [OFFER]
Target audience (job titles, seniority, industry, company size): [AUDIENCE]
Their main problem and what they care about: [PAIN POINTS]
Proof we can mention (results, customers, awards) — only real facts: [PROOF]
Campaign goal (leads, sign-ups, traffic): [GOAL]
Tone: [TONE]

Write 5 ad variants, each with a different angle: pain, outcome, proof, curiosity and contrarian.
For each variant give:
- Intro text: one version under 150 characters and one longer version under 600 characters (the first line must work alone before "see more").
- Headline under 70 characters.
- Description under 100 characters.
- Best CTA button from LinkedIn's standard options.
- The audience segment it suits best.
Then recommend 2 variants to test first and what result would tell me which angle wins.
Do not invent numbers, logos or testimonials.
```

## How to use it

1. **Be exact about job titles and seniority**, because LinkedIn targets by role.
2. **Use only proof you can stand behind**; leave the field empty if you have none.
3. **Test two angles at a time** with the same image so the copy is the only difference.

## Tips

- Lead-gen form ads usually need shorter copy than ads sending people to a page.
- Turn the winning angle into a landing page with the [landing page hero copy prompt](/prompts/landing-page-hero-copy/).
- Compare with the [Facebook ad copy prompt](/prompts/facebook-ad-copy-variants/) if you run both channels.
