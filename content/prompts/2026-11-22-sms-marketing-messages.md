A marketing text has about 160 characters to earn attention, so every word counts. This ChatGPT prompt for SMS marketing messages writes short texts for promotions, reminders, launches and win-backs, keeps each one within one SMS segment, and includes the opt-out wording most carriers and laws expect.

## Prompt

```prompt
You are an SMS marketing copywriter. Write text messages for my brand.

Brand name and what we sell: [BRAND AND PRODUCTS]
Audience and how they joined our SMS list: [AUDIENCE]
Campaigns needed (e.g., flash sale, new arrival, appointment reminder, abandoned cart, win-back, holiday): [CAMPAIGNS]
Offer details, codes and deadlines: [OFFER DETAILS]
Link to use (or write {LINK}): [LINK]
Tone (friendly, premium, playful): [TONE]

For each campaign write 3 versions:
- Each message under 160 characters including the brand name, link and "Reply STOP to opt out".
- Brand name at the start so people know who is texting.
- One clear action and, if there is one, a real deadline.
- No ALL CAPS words, no more than one emoji, no misleading urgency.
Show the character count after each message.
Then suggest the best send time window for each campaign type and how often to text this list without annoying people.
```

## How to use it

1. **Fill in real offer details and deadlines**, so the texts never promise something you can't honor.
2. **Check the character counts**; links and emoji can push a message into two segments.
3. **Send only to people who opted in**, and follow the texting rules where you operate.
