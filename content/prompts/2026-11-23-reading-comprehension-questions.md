Writing good reading comprehension questions takes time, and many end up as simple recall. This prompt creates a balanced set for any passage you provide: literal, inference, vocabulary-in-context and author's purpose questions at the right grade level, with an answer key and a short extension activity.

## Prompt

```prompt
Create reading comprehension questions for this text.

Grade level and reading level: [GRADE AND LEVEL]
Text (paste it, or describe it if it's a book chapter): [TEXT]
Skills to focus on: [SKILLS, e.g. main idea, inference, vocabulary, text evidence, author's purpose]
Number of questions and format: [NUMBER AND FORMAT, e.g. 8 questions, mix of multiple choice and short answer]
Support needs: [SUPPORT, e.g. English learners, students reading below grade level]

Write:
1. Questions in order from literal to deeper thinking, each labeled with the skill it checks.
2. At least two questions that require citing evidence from the text.
3. 3 vocabulary-in-context questions using words from the text.
4. An answer key with sample answers and what a full-credit answer includes.
5. A simpler version of 3 questions for students who need support.
6. One short extension or discussion activity.
Base every question and answer on the text only.
```

## How to use it

1. **Paste the exact passage** students will read.
2. **Check the answer key** against the text before using it.
3. **Use the simpler versions** for small-group support.
