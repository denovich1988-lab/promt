A map makes a fantasy world feel real for readers and tabletop players. These Midjourney fantasy map prompts describe an original continent in a classic hand-drawn style, with terrain, cities and decorative elements, while leaving room for the place names you add yourself.

## Prompt

```prompt
Original fantasy world map seen from above, hand-drawn [STYLE, e.g. ink and parchment, watercolor atlas, antique engraving], showing [GEOGRAPHY, e.g. a crescent-shaped continent with a mountain spine, a great inland lake, scattered islands to the east], dense forests, rivers flowing to the sea, small castle and town icons, [EXTRA, e.g. a compass rose, sea serpents in the ocean, decorative border], aged paper texture, muted [PALETTE] colors, top-down orthographic view, no text, no labels --ar 3:2 --stylize [100-300]
```

## How to use it

1. **Describe the shape of the land** clearly; it is the part that makes your world unique.
2. **Add names and borders yourself** in a design tool, because AI text on maps is unreliable.
3. **Generate regional close-ups** with the same style words for more detailed areas.

## Tips

- Add the `--tile` parameter in Midjourney if you want a texture that repeats, such as an ocean for a game board.
- Design the places on the map with the [Midjourney fantasy concept art](/prompts/midjourney-fantasy-concept-art/) prompt.
