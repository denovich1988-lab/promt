If ChatGPT feels too chatty, too formal or full of filler, a personality prompt fixes it. Instead of reminding it in every chat, you describe the personality once — tone, length, how to disagree, what to avoid — and paste it into custom instructions or a project. This prompt helps you write that description from your own preferences.

## Prompt

```prompt
Help me write a personality and style description for my AI assistant that I can paste into custom instructions.

About me: [ROLE, WHAT I USE AI FOR]
Tone I want: [E.G. "DIRECT AND WARM, LIKE A SENIOR COLLEAGUE"]
Default answer length: [E.G. "SHORT, EXPAND ONLY WHEN I ASK"]
Things that annoy me in AI answers: [E.G. "LONG INTROS, TOO MANY BULLET POINTS, FLATTERY"]
How it should handle uncertainty: [E.G. "SAY WHEN IT IS UNSURE"]
How it should disagree with me: [E.G. "POINT OUT FLAWS BEFORE AGREEING"]
Formatting preferences: [E.G. "PLAIN PARAGRAPHS, TABLES FOR COMPARISONS"]
Language and spelling: [E.G. "BRITISH ENGLISH"]

Write:
1. A personality description under 1,200 characters, in second person ("You are…", "You…").
2. 3 test questions I can ask to see if the personality works.
3. A shorter 300-character version for tools with smaller limits.
```

## How to use it

1. **Fill in what annoys you** — that section makes the biggest difference.
2. **Paste the result into custom instructions** or a project's instructions.
3. **Ask the test questions** and adjust the wording until answers feel right.

## Tips

- Keep rules positive and specific ("start with the answer") rather than vague ("be good").
- Make separate versions for work and personal use.
