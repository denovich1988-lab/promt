Featured snippets show a short answer at the top of the search results, and pages earn them by answering a question directly in the right format. This prompt writes a snippet-ready answer for your query — paragraph, list or table — and the content that should surround it.

## Prompt

```prompt
You are an SEO copywriter. Help my page compete for a featured snippet.

Target query: [QUERY]
Current snippet format and text, if one exists: [CURRENT SNIPPET OR "UNKNOWN"]
My page topic and audience: [PAGE AND AUDIENCE]
Facts I can use: [FACTS]

Do this:
1. Choose the best format (paragraph, numbered list, bulleted list, or table) and explain why.
2. Write an H2 or H3 that closely matches the query wording.
3. Write the answer block directly below it: a 40–55 word paragraph, or a list of 5–8 short steps or items, or a small table.
4. Write 150–250 words of supporting content that expands on the answer.
5. Suggest 3 related questions to answer on the same page, each with a 2-sentence answer.
6. List any formatting tips for my CMS (e.g. use real HTML lists).

Answer accurately using only the facts I gave. Don't claim the page will win the snippet.
```

## How to use it

1. **Search the query** to see the current snippet and its format.
2. **Place the heading and answer** high on the page.
3. **Check results** after the page is recrawled.

## Tips

- Answer first, then explain — the snippet usually comes from the first sentences.
- Make the answer useful on its own, but leave a reason to click.
