Wanting to draw every day is easy; deciding what to draw is not. Random lists of drawing prompt ideas are often too hard, too easy or simply boring. This prompt creates a set of drawing prompts made for you: your level, the subjects you like, the skill you want to improve and how much time you have, so each prompt builds a real skill. Teachers can use it for class warm-ups too.

## Prompt

```prompt
You are an art teacher who keeps students drawing every day. Create drawing prompt ideas for me. I will draw them myself.

My level: [LEVEL, e.g. complete beginner, hobbyist, art student]
Subjects I enjoy: [SUBJECTS, e.g. animals, people, buildings, fantasy]
Skill I want to improve: [SKILL, e.g. perspective, shading, hands, gesture, composition]
Materials: [MATERIALS, e.g. pencil, ink, digital, watercolor]
Time per day: [TIME]
Number of days: [NUMBER OF DAYS]
For a class? [CLASS DETAILS, or "no, just me"]

For each day give:
1. The drawing prompt in one sentence, specific and fun.
2. The skill focus and one tip for it.
3. A time limit and whether to use references (and what to search for).
4. A small twist for extra challenge.
Make the prompts get gradually harder, mix observation drawing with imagination, and add a review day every 7 days where I redraw an earlier piece.
```

## How to use it

1. **Set a realistic daily time**, even 10 minutes works.
2. **Date each sketch** so you can see your progress.
3. **Use the review days** to compare old and new drawings.
