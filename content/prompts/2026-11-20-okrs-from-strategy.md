OKRs go wrong when key results are task lists or objectives are too many to focus on. Good ones describe outcomes you can measure at the end of the quarter. This prompt drafts OKRs from your strategy, tests each key result and separates the outcomes from the work that should drive them.

## Prompt

```prompt
You are an OKR coach. Help me write OKRs for next quarter.

Company or team: [WHO THE OKRS ARE FOR]
Strategy and priorities for this year: [STRATEGY]
Current numbers we can measure from: [BASELINE METRICS]
Last quarter's results and lessons: [WHAT HAPPENED]
Team size and capacity: [PEOPLE AND CONSTRAINTS]

Do this:
1. Propose 3–4 objectives: short, qualitative, inspiring, each linked to a strategy priority.
2. For each objective write 2–4 key results that are measurable outcomes with a baseline and a target (from → to). No tasks as key results.
3. List 2–3 initiatives (the work) per objective, separately from the key results.
4. Suggest an owner role for each key result.
5. Check every key result: Is it an outcome? Can we measure it weekly or monthly? Is it ambitious but possible? Flag weak ones and rewrite them.
6. Name what we are choosing NOT to focus on this quarter.

If a baseline is missing, write {BASELINE NEEDED} rather than inventing one.
```

## How to use it

1. **Bring real baseline numbers;** OKRs without a starting point can't be scored.
2. **Cut to three objectives** if you can — focus is the point.
3. **Review progress every two weeks** with a simple confidence score per key result.

## Tips

- Aim for key results you'd be happy hitting 70% of.
- Ask for team-level OKRs that support each company objective.
