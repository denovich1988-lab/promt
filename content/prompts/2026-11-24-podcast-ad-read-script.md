Host-read podcast ads work because listeners trust the host's voice, which disappears when the script sounds like a press release. This prompt writes a podcast ad read with talking points and a script in the host's style, honest claims and a call to action listeners can remember.

## Prompt

```prompt
Act as a podcast producer who writes sponsor reads. Write a host-read ad.

Podcast name, topic and host style: [PODCAST AND HOST STYLE]
Sponsor and product: [SPONSOR AND PRODUCT]
Key points the sponsor requires: [REQUIRED POINTS]
Host's real experience with the product, if any: [HOST EXPERIENCE]
Offer and code or URL: [OFFER AND CODE]
Placement and length (pre-roll 15–30 sec, mid-roll 60 sec): [PLACEMENT AND LENGTH]
Claims we cannot make: [RESTRICTED CLAIMS]

Write:
1. Bullet talking points for hosts who ad-lib.
2. A full script for the chosen length, written to be spoken, with a natural transition in and out of the episode.
3. A shorter backup version.
4. The code and URL said twice, spelled out if needed.
5. A required disclosure line (e.g. "this episode is sponsored by").
Only include personal experience the host actually has. No invented results.
```

## How to use it

1. **Ask the host what they really think** of the product and use their words.
2. **Read it aloud** and cut anything that sounds written.
3. **Check sponsor approval** before recording.
