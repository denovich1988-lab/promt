Midjourney is strongest as a source of raw material for designers: seamless patterns, textures, abstract backgrounds and poster art that you finish with real type in Figma, Illustrator or Photoshop. These Midjourney prompts for graphic design ask for assets with the space, palette and format a layout needs, instead of finished designs with garbled text.

## Prompt

```prompt
You are a senior graphic designer who uses Midjourney to make design assets. Write 4 Midjourney prompts for my project.

Project and where the asset will be used: [PROJECT, e.g. café menu cover, conference slides, packaging]
Asset type: [SEAMLESS PATTERN / TEXTURE / ABSTRACT BACKGROUND / POSTER ARTWORK / SPOT ILLUSTRATION / ICON STYLE STUDY]
Brand colors (hex if possible): [COLORS]
Mood and style references in words: [STYLE, e.g. Swiss modernist, risograph print, organic paper cut]
Layout needs: [e.g. empty top third for a headline, centered subject, edge-to-edge pattern]
Final size and ratio: [RATIO]
Midjourney version and settings I use: [VERSION / STYLIZE / RAW]

For each prompt:
- Describe the asset in design terms (shapes, line weight, texture, color count, negative space)
- No text or lettering in the image; mention "no text" and use --no text, letters, watermark
- Add --ar, and --tile for seamless patterns
- Suggest a --stylize value and say why

Then add: how to finish each asset in a design tool (vectorise, recolor to exact hex, add type), and one variation to test.
```

## How to use it

1. **Use --tile** for patterns and check the seams by tiling the result in your design tool.
2. **Recolor to exact brand hex values** after export; Midjourney colors are approximate.
3. **Add all text in your design tool**, not in Midjourney.
