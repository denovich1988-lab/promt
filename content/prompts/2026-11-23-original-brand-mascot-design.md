A friendly mascot can make a small brand memorable on packaging, social posts and the website. This prompt designs an original brand mascot: it starts from your brand's personality, then describes the character's shape, colors and expressions, and asks for a character sheet with several poses so you can use the same mascot everywhere.

## Prompt

```prompt
Original brand mascot character sheet for [BRAND TYPE, e.g. a plant-based snack brand, a kids' coding school]. The mascot is a [CHARACTER, e.g. round cheerful sprout with leaf ears, small robot with a big curious face] whose personality is [PERSONALITY, e.g. playful, helpful, a little clumsy]. Simple, rounded shapes that are easy to recognize at small sizes, brand colors [COLORS], clean bold outlines, flat shading. Character sheet layout on a plain white background: front view, side view, back view, and 4 poses and expressions (waving hello, thinking, celebrating, pointing at something). Consistent proportions and colors in every view. [STYLE, e.g. modern 2D cartoon, soft 3D render]. No text, no logos, not based on any existing character.
```

## How to use it

1. **Define the brand's personality first**, then pick a character that fits it.
2. **Generate several sheets** and choose the simplest design: it will work best at small sizes.
3. **Have a designer clean it up** as vector art before using it in print or packaging.
