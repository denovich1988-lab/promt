Repeating patterns for fabric, gift wrap or wallpaper need edges that join with no visible seam. Midjourney seamless pattern prompts work best when you name the motif, density, style and a small palette, then add the tile parameter so the image repeats cleanly. This template gives you all of that, plus variations for different products.

## Prompt

```prompt
Seamless repeating pattern of [MOTIF, e.g. winter berries and pine sprigs], [STYLE, e.g. hand-drawn gouache, flat vector, mid-century, block print], [DENSITY, e.g. evenly spaced, dense all-over, tossed scattered], palette of [3-5 COLORS] on a [BACKGROUND COLOR] background, flat lighting, no shadows, no text, crisp edges, designed for [USE, e.g. fabric, wrapping paper, wallpaper] --tile --ar 1:1 --stylize [50-250]
```

## How to use it

1. **Keep the background a flat color** so the repeat is easy to check.
2. **Test the tile** by placing four copies side by side in any image editor before printing.
3. **Upscale the best one** and vectorize it if a print supplier needs very large sizes.

## Tips

- For Flux or GPT Image, drop the parameters and add "tileable texture, edges match perfectly" instead, then check the seams yourself.
- Want single graphics instead of repeats? Try the [Midjourney graphic design assets](/prompts/midjourney-graphic-design-assets/) prompt.
- Selling prints? Read the platform's rules on AI-generated designs before listing.
