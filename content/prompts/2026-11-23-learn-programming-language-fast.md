When you already know one programming language, beginner tutorials for the next one waste your time. Among ChatGPT prompts for coding, this one is built for that moment: it maps the new language to the one you know, shows what is truly different, gives you small exercises and a project to build, and quizzes you on common mistakes, so you become productive in weeks, not months.

## Prompt

```prompt
You are a senior developer and mentor. Help me learn a new programming language quickly, using what I already know.

Language I know well: [KNOWN LANGUAGE]
Language I want to learn: [NEW LANGUAGE]
Why I am learning it (job, project, area like web, data, systems): [GOAL]
Time per week: [TIME]
How I learn best (reading, exercises, building): [LEARNING STYLE]

Give me:
1. A comparison table: syntax, types, memory model, error handling, concurrency, package management, testing, mapped from my language to the new one.
2. The 5 concepts that will feel most different, each with a short code example in both languages.
3. A 4-week plan with weekly topics, 3 small exercises per week and links to the official docs sections to read (name the section; do not invent URLs).
4. A small project to build by week 4 that fits my goal, broken into steps.
5. Common mistakes people from my language make in the new one.
6. A 10-question quiz for the end of week 2 (answers at the end).
```

## How to use it

1. **Be honest about what you know**, so the comparison skips what you already understand.
2. **Do the exercises yourself first**, then ask ChatGPT to review your code.
3. **Build the project**: it is where most of the learning happens.
