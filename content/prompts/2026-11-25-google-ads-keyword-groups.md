Search campaigns waste budget when one ad group holds dozens of unrelated keywords: ads don't match searches, quality drops and costs rise. Tight keyword groups, each with one theme and one landing page, fix that. This prompt organizes your services and seed keywords into themed ad groups with match types and starting negatives, so you can set up or clean up a campaign quickly.

## Prompt

```prompt
Build Google Ads keyword groups for a search campaign.

Business and offer: [DESCRIPTION]
Location targeting: [AREA]
Services or products to advertise (with landing page URLs): [LIST]
Seed keywords or search terms report data: [PASTE KEYWORDS]
Monthly budget: [BUDGET]
Customers we don't want: [e.g. DIY, jobs, free, students]

1. Group keywords into ad groups with one clear theme each; name each group.
2. For each group: 5–15 keywords with suggested match type (exact or phrase, broad only if I have strong conversion data), and the landing page that fits best.
3. Intent label per group: high (ready to buy), medium (comparing), low (researching). Suggest which to launch first with my budget.
4. Campaign-level negative keyword list grouped by theme.
5. Two headline ideas per ad group that echo its main keyword.

Don't invent search volumes or CPCs. If a landing page doesn't exist for a group, say so.
```

## How to use it

1. **Paste real search terms** if you already run ads; they show how people actually search.
2. **Launch high-intent groups first** on a limited budget.
3. **Review the search terms report weekly** and add negatives.

## Tips

- Use Keyword Planner for volume and bid estimates before launching.
- If a group needs a different message, it needs a different landing page too.
