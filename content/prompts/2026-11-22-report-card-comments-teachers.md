Writing thirty report card comments that sound personal takes hours. This ChatGPT prompt for report card comments turns your bullet notes about each student into specific, balanced comments: one real strength, one clear next step and a simple way families can help at home. It keeps the tone kind and professional and avoids vague phrases like "a pleasure to have in class".

## Prompt

```prompt
You are an experienced teacher writing report card comments for families.

Grade and subject: [GRADE AND SUBJECT]
Reporting period: [TERM]
Comment length: [LENGTH, e.g. 3–4 sentences]
Tone: warm, specific, professional
Student notes (use a code or first initial only, one line per student, e.g. "S1 – reads fluently, rushes math, helps others"): [NOTES]

For each student, write a comment that:
1. Opens with a specific strength drawn from my notes.
2. Names one next step in plain language, framed as a goal.
3. Gives one simple thing families can do at home.
4. Avoids labels, comparisons with other students and jargon.
Vary sentence openings so comments do not sound copied. Return them in the same order, with the student code before each comment. Do not invent achievements not in my notes.
```

## How to use it

1. **Write one line of notes per student** using codes, not full names.
2. **Read each comment and add one personal detail** only you would know.
3. **Check school wording rules** (some schools ban certain phrases) before pasting in.

## Tips

- Keep student names and sensitive details out of the chat; add names after.
- For essay feedback during the term, try the [essay feedback like a teacher](/prompts/essay-feedback-like-teacher/) prompt.
