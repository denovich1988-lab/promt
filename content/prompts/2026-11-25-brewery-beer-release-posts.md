Small breweries release new beers often, and each one needs posts, a menu blurb and an email, usually written the night before. ChatGPT prompts for breweries can turn the brewer's notes into a complete release kit in one go. This prompt keeps the style details accurate and the tone fun, without the clichés that make every beer description sound the same.

## Prompt

```prompt
Act as the social media manager for a craft brewery.

Brewery: [NAME, CITY, VIBE]
New beer: [NAME, STYLE, ABV, HOPS/MALTS/ADJUNCTS, BREWER'S TASTING NOTES]
Story behind it: [E.G. COLLAB, LOCAL INGREDIENT, ANNIVERSARY]
Release details: [DATE, TIME, FORMATS (DRAFT/CANS), LIMITS, FOOD TRUCK OR EVENT]
Audience: [E.G. LOCAL REGULARS, BEER ENTHUSIASTS]

Write:
1. 3 social posts: a teaser (3 days before), release day, and a "last chance" post, each with a caption and image idea.
2. A taproom menu description (under 25 words) and a chalkboard version (under 10 words).
3. A release email with subject line, the story in 3 sentences, tasting notes and release details.
4. 5 short, specific flavor descriptions to replace overused words like "crushable" and "juicy".

Use only the ingredients and numbers I gave. Keep it fun but include a "please drink responsibly" line in the email.
```

## How to use it

1. **Get the brewer's notes first**; ABV and ingredients must be exact.
2. **Schedule the three posts** as soon as the release date is set.
3. **Ask regulars which description fit best** and save the winners for future releases.

## Tips

- Ask for a version for beer rating apps or distributor sell sheets.
- Check your local alcohol advertising rules for limited releases and giveaways.
