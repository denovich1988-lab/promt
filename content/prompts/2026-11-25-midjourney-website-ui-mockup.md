Image models can't build a working website, but they are good at fast visual direction: a hero layout, a color mood or a style for a client mood board. Midjourney prompts for website design work best when you describe the page type, layout blocks and visual style like a designer briefing a mockup. This prompt writes those prompts and reminds you which parts need a real design tool afterwards.

## Prompt

```prompt
Write 6 image prompts for website design mockups.

Website type and audience: [e.g. booking site for a yoga studio, SaaS analytics tool]
Page: [HOME HERO / FULL LANDING PAGE / PRICING / DASHBOARD / MOBILE APP SCREEN]
Visual style: [e.g. minimal Swiss, soft pastel 3D, dark tech, editorial serif]
Brand colors: [COLORS]
Device frame: [DESKTOP BROWSER / LAPTOP / PHONE / NONE, FLAT SCREEN]
Generator: [MIDJOURNEY / GPT IMAGE / FLUX]

Each prompt should describe:
- Layout blocks from top to bottom (nav bar, hero headline area, image, cards, CTA)
- Typography feel, spacing and grid
- Color use and imagery style
- View: flat UI screenshot or device mockup, and aspect ratio

Use placeholder text areas rather than asking for readable copy. Vary the 6: 3 layout options in one style, then 3 style options for the best layout.
After the prompts, list what to rebuild in a design tool (real text, accessibility contrast, components).
```

## How to use it

1. **Generate layouts first**, pick one, then explore styles on that layout.
2. **Use the images as a mood board** for the client or your designer.
3. **Rebuild the chosen direction** in a proper design tool with real content.

## Tips

- Ask for "flat UI screenshot, no device" when you want details you can trace.
- AI text in images is often garbled; don't rely on it for copy.
