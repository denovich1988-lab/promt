An llms.txt file is a proposed standard: a Markdown file at your site root that summarises the site and links to the pages that matter most for AI tools. Support from AI companies is still limited and may change, but the file is quick to make. This prompt drafts an llms.txt file from your site structure, without padding or keyword stuffing.

## Prompt

```prompt
Act as a technical SEO specialist. Draft an llms.txt file for my website.

Site name and domain: [SITE AND DOMAIN]
What the site or company does, in plain words: [DESCRIPTION]
Main audiences: [AUDIENCES]
Key pages with URLs and one-line descriptions (docs, products, pricing, guides, policies):
[KEY PAGES]
Pages to leave out: [EXCLUDE]

Write:
1. The file in the proposed llms.txt format: an H1 with the site name, a short blockquote summary, a few sentences of context, then H2 sections with Markdown link lists ("[Title](URL): description").
2. An "Optional" section for secondary pages.
3. Notes on which pages should have clean Markdown or text versions.
4. A short checklist to keep the file updated.
Use only the URLs I gave. Keep descriptions factual and short.
```

## How to use it

1. **List 10–30 of your most useful pages**, not every URL.
2. **Upload the file** as /llms.txt at your site root.
3. **Update it** when you add or remove key pages.
